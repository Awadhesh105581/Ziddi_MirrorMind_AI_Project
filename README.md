# Ziddi MirrorMind – Your Digital AI Clone

An Indian-language AI voice assistant powered by Gemini API that speaks like YOU.
Supports: Voice I/O, Gemini AI, Memory, Telegram bot, GUI-ready.

---

## Setup:
- Put your API keys in `config.py`
- Run: `pip install -r requirements.txt`
- Launch: `python main.py`
