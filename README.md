# 🤖 Ziddi MirrorMind AI Project

> **"सोच से समाधान तक"** – एक AI सिस्टम जो आपकी सोच, बातचीत और व्यक्तित्व को डिजिटल रूप में दोहराने की क्षमता रखता है।

## 📌 Introduction
Ziddi MirrorMind AI एक एडवांस AI प्रोजेक्ट है जो **व्यक्तिगत AI क्लोन** बनाने के लिए डिज़ाइन किया गया है।  
यह आपके बातचीत के पैटर्न, राय, और व्यक्तित्व को समझकर उसी अंदाज़ में जवाब देता है।  
इसे आप **Telegram Bot**, **Voice Interaction**, और **Custom AI Features** के साथ इंटीग्रेट कर सकते हैं।

## 🚀 Features
- 🧠 **Personality Cloning** – आपके स्टाइल में जवाब देना
- 🗣 **Voice Interaction** – रियल-टाइम वॉयस इनपुट और आउटपुट
- 💬 **Telegram Bot Integration**
- 📜 **Opinion Memory** – पुरानी बातचीत याद रखना
- 🎭 **Poetic Responses** – क्रिएटिव अंदाज़ में जवाब
- 🔄 **Custom Command System**

## 🛠 Tech Stack
- **Python 3.10+**
- **OpenAI API / ChatGPT**
- **Telegram Bot API**
- **SpeechRecognition**
- **gTTS / pyttsx3**
- **Firebase / JSON Storage**

## 📥 Installation
```bash
# Clone the repo
git clone https://github.com/Awadhesh105581/Ziddi_MirrorMind_AI_Project.git

# Go to project folder
cd Ziddi_MirrorMind_AI_Project

# Install dependencies
pip install -r requirements.txt

# Usage
python main.py
